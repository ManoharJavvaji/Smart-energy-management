# Smart Energy Management System

An occupancy-based electricity management prototype
designed for hostels, hospitals, schools and institutions.

## Features

- Multi-room occupancy simulation
- Automatic light and fan control
- Configurable 45-minute absence delay
- Manual ON/OFF override
- Sensor failure protection
- Network failure protection
- Activity and safety logs
- Estimated energy savings

## Technology Stack

- HTML
- CSS
- JavaScript
- GitHub
- Microsoft Azure Static Web Apps

This prototype does not control physical electrical circuits.
